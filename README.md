## ✦ About the Project

**Sanad | سند** is an AI-powered academic guidance application designed specifically for students at the **College of Computer Science and Engineering, Prince Sattam bin Abdulaziz University**.

The project aims to make college-related academic information easier to access by giving students a place to ask questions and receive AI-assisted guidance relevant to their college.

I built the application using **Bubble** and integrated an AI service through an **API**. To improve the relevance and accuracy of its responses, I added college-related reference files to the application's data, so the AI guidance can be informed by information specific to the college rather than relying only on general answers.

## ✦ How It Works

1. **Students ask academic questions** through the application's interface.
2. **AI integration supports responses** through the connected API.
3. **College-specific reference files** added to the application's data provide relevant context to help improve response accuracy.

> Responses are AI-generated and should be verified against official university sources when making important academic decisions.
