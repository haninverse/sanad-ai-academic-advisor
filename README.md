## ✦ About the Project

**Sanad | سند** is an AI-powered academic guidance application built with **Bubble**. It explores how AI-assisted tools can support students as they navigate academic questions and decisions.

The project combines a user-friendly application interface with API integration to deliver an accessible academic guidance experience.

## ✦ Project Highlights

- **AI-assisted academic guidance** — an interface for students to seek academic support.
- **Bubble application development** — built using a no-code development platform.
- **API integration** — connects the application to external AI capabilities.
- **User-centered experience** — focuses on making academic guidance approachable.
